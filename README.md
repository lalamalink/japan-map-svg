# ディフォルメ都道府県日本地図 SVG

ディフォルメされた都道府県別の日本地図SVG素材です。  
都道府県ごとの `path` に、`data-code` と `data-name` を付与しています。

## Files

- `svg/deformed-japan-prefecture-map.svg`  
  メタデータ入りのSVG本体です。

## Notes

- この素材は正確な測量用・行政手続き用の地図ではありません。
- ディフォルメ表現のため、実際の地形・面積・距離・位置関係とは異なります。
- SVG内には `<title>`、`<desc>`、`<metadata>`、XMLコメントとして素材情報を記載しています。
